# HTML-CSS – Curso em Vídeo

Repositório com exercícios práticos dos **cinco primeiros módulos** do curso de **HTML5 e CSS3**, do **Curso em Vídeo** (Professor Gustavo Guanabara).

---

##  Estrutura do Repositório

- **Desafios/** – Pasta contendo desafios propostos nos módulos do curso.
- **Exercicios/** – Pasta com os exercícios realizados para praticar os conteúdos.
- **.gitattributes** – Arquivo de configuração para Git.
- **LICENSE** – Licença MIT para uso, modificação e distribuição.
- **README.md** – Este arquivo, apresentando o conteúdo e instruções.
- Linguagens utilizadas: **HTML (~90 %)** e **CSS (~10 %)**

---

##  Módulos Contidos

Este repositório reúne os **primeiros cinco módulos** do curso:

1. **Módulo 1** – Fundamentos do HTML: estrutura básica, tags essenciais.
2. **Módulo 2** – Elementos semânticos: cabeçalhos, parágrafos, listas, links, imagens.
3. **Módulo 3** – Fundamentos do CSS: seletores, propriedades, cores, fontes.
4. **Módulo 4** – CSS avançado: layout com `display`, `box model`, classes e IDs.
5. **Módulo 5** – Aplicando estilo prático: layout simples, formatação básica, responsividade essencial.

*(A descrição acima é um exemplo aplicável ao curso; você pode substituir pelos tópicos reais de cada módulo conforme o seu aprendizado.)*
